# 🛡️ Ryvora Cyber Range — Detection Rules & Playbooks

Welcome to the **Ryvora Cyber Range Detection Repository**.  
This repo contains the **custom detection rules, common investigation queries, and playbooks** used in the Ryvora cyber range.  

Every incident in the range ties back to a **real detection rule** with supporting queries and analyst workflows.  
You can use these rules to:  
- Learn how SOC analysts investigate incidents  
- Practice with **Azure Sentinel (KQL)** or **Wazuh rules**  
- Explore MITRE ATT&CK–mapped scenarios
